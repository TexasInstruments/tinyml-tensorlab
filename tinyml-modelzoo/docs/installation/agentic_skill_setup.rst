=========================
Agent Skill (Claude Code)
=========================

.. note::

   The **Tiny ML Agent Skill for Claude Code** was introduced in release 1.4.0 as a
   beta feature, distributed through the ``tinyml-tensorlab`` repository. The 1.5.0
   ``tinyml-modelzoo`` package and its documentation do not ship an agent skill, so there is
   nothing to set up here for 1.5.0.

If you used the skill with 1.4.0, see the
`1.4.0 user guide <https://software-dl.ti.com/C2000/esd/mcu_ai/user_guide/index.html>`_
for its setup. To get an equivalent hands-on workflow with 1.5.0, use:

* :doc:`/getting_started/quickstart` to run an example,
* :doc:`/CONFIG_YAML_GUIDE` to adapt a config to your data and device,
* :doc:`/BRING_YOUR_OWN_MODEL` to add your own model.
